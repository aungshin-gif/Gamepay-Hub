01

ဇာတ်လမ်း

GamePay Hub store ကနေ ကိုယ်ပိုင် AI Gateway ဆီ ဘယ်လိုရောက်လာသလဲ၊ ဘာကိုဆုံးဖြတ်ခဲ့သလဲ။

စခဲ့တဲ့နေရာ

GamePay Hub က မြန်မာ customer တွေအတွက် AI tools၊ streaming၊ VPN၊ game top-up တွေကို ရောင်းတဲ့ website ပါ။ GitHub Pages ပေါ်မှာ တင်ထားပြီး Supabase ကို backend အဖြစ်သုံးတယ်။ Owner က code ကို ကိုယ်တိုင်မရေးဘဲ Claude ကို ခိုင်းပြီး ဆောက်တဲ့ "vibe coding" သမားပါ — syntax ထက် ပုံစံ (mental model) နဲ့ ရလဒ် ကို ဂရုစိုက်တယ်။

စိတ်ကူး

Store အပြင် နောက်ထပ်တစ်ခု လိုချင်လာတယ် — AI API token တွေပါ။ ဆန္ဒက ၃ ခု ရောနေတာ:

  1. ကိုယ်တိုင် chatbot ထဲမှာ သုံးချင်တယ်။
  2. Key တွေကို ကိုယ်တိုင် ထုတ်ပေးချင်တယ် (တစ်ယောက်ချင်းစီ၊ ကန့်သတ်ပြီး)။
  3. နောက်ဆုံး website ပေါ်မှာ ကိုယ့်ပုံစံနဲ့ token အသုံးပြုမှုကို ပြချင်တယ်။

အရေးကြီးတဲ့ ဆုံးဖြတ်ချက် ၃ ခု

၁။ အပေါဆုံးကို မလိုက်ဘူး

အင်တာနက်ပေါ်မှာ Claude/GPT ကို အလွန်ပေါတဲ့စျေးနဲ့ ရောင်းတဲ့နေရာတွေ ရှိတယ်။ ဒါတွေက ခိုးကတ်/ခိုးထားတဲ့ key ဖြစ်နိုင်လို့ မဝယ်ဘူး။

၂။ ပြန်မရောင်းဘူး

Provider တွေရဲ့ စည်းမျဉ်း (key ရောင်းဝယ်တာ၊ account ပြန်ငှားတာ တားမြစ်) ကိုဖတ်ပြီး ကိုယ်သုံး + team giveaway နဲ့ပဲ သွားမယ်လို့ ဆုံးဖြတ်တယ်။

၃။ ကိုယ်ပိုင် Gateway

Open-source new-api ကို Railway မှာ တင်ပြီး key တွေကို ကိုယ်တိုင်ထုတ်မယ်။ Upstream key (DeepSeek) ကို gateway ထဲပဲ သိမ်းမယ်။

ပန်းတိုင်

Team project ထဲက member တစ်ယောက်ချင်းစီကို DeepSeek flash 1M token စီ giveaway ပေးမယ်။

ဘာကြောင့်

အကျိုးအမြတ်ရောင်းဖို့ထက် ကန့်သတ်ပြီး ခွဲဝေပေးတတ်ဖို့ က ပိုအရေးကြီးတယ်လို့ တွေ့ခဲ့တယ်။ ကန့်သတ်ချက်မရှိရင် တစ်ယောက်က ပိုက်ဆံအကုန်သုံးသွားနိုင်တယ်၊ ဒါကြောင့် Gateway လိုတာ။

02

စိတ်ထဲမှာ မြင်ရမယ့်ပုံများ

ခလုတ်မနှိပ်ခင် ပုံစံကို နားလည်ထားရင် ပြဿနာတက်တိုင်း ဘယ်နေရာမှာလဲ ကိုယ်တိုင်ခန့်မှန်းနိုင်မယ်။

Token ဆိုတာ

AI က စာကို token လို့ခေါ်တဲ့ အပိုင်းအစလေးတွေအဖြစ် ဖတ်တယ်၊ ရေးတယ်။ စျေးနှုန်းကို "token ၁သန်း = $ဘယ်လောက်" နဲ့ တွက်တယ်။ မေးတာ (input) နဲ့ ဖြေတာ (output) စျေးမတူဘူး။

အကြံ

DeepSeek flash က default အနေနဲ့ စဉ်းစား (thinking) mode ဖြစ်တယ်။ စဉ်းစားတဲ့ token တွေကိုလည်း output အဖြစ် ရေတွက်ပြီး ပိုက်ဆံကောက်တယ်။ ဒါကြောင့် ရိုးရိုးမေးခွန်းလေးတောင် မျှော်မှန်းထက် token ပိုကုန်နိုင်တယ်။

API key ဆိုတာ

Key ဆိုတာ "ဝင်ခွင့်ပါတ်စ်" ပါ။ sk-... နဲ့ စတဲ့ စာလုံးအရှည်ကြီးတစ်ခု။ ပြင်ပ app က ဒီ key ကို ပြမှ Gateway က ဝင်ခွင့်ပေးတယ်။ Key တစ်ခုချင်းစီမှာ သုံးခွင့်ပမာဏ (quota) သတ်မှတ်လို့ရတယ်။

Gateway ဆိုတာ

ဟိုတယ်ရဲ့ reception လို စဉ်းစားပါ။ Customer (app) က ဟိုတယ်မီးဖိုချောင် (DeepSeek) ကို တိုက်ရိုက်မဝင်ရဘူး — reception (Gateway) ကို အရင်ပြောရတယ်။ Reception က (၁) key မှန်လား စစ်၊ (၂) quota ကျန်လား စစ်၊ (၃) သုံးသလောက် နှုတ်၊ (၄) မှတ်တမ်းတင်။ ပြီးမှ ကိုယ့်ရဲ့ အစစ်အမှန် key နဲ့ မီးဖိုချောင်ကို ပြောပေးတယ်။

လုံခြုံရေး

အကြီးဆုံး အကျိုးက DeepSeek key ကို member တွေ မမြင်ရတာ ပါ။ သူတို့မြင်ရတာ Gateway ထုတ်ပေးတဲ့ key ပဲ။ ပေါက်သွားရင် အဲဒီ key တစ်ခုတည်း ဖျက်ရုံပဲ။

Credit ဆိုတာ

Credit (quota) က လူတစ်ယောက်ချင်းစီ၊ key တစ်ခုချင်းစီအတွက် "သုံးခွင့်ရှိတဲ့ အတွင်းစာရင်း" ပါ။ ပိုက်ဆံအစစ်မဟုတ်ဘူး၊ ဂဏန်းတစ်ခုပဲ — ဒါပေမဲ့ သုံးတိုင်း ကျတယ်၊ ကုန်ရင် Gateway က ပိတ်တယ်။ ရှင်တစ်ယောက်တည်းသုံးရင် မထိတွေ့ရတာက ရှင့်မှာ အစကတည်းက ပမာဏကြီးကြီး ($200 ဝန်းကျင်) ပါလာလို့။

A4 · Termux chat script (chat.py)

Key မပါ။ GW_KEY ကို environment ကဖတ်တယ်။ curl ကိုခေါ်တာက Python urllib နဲ့ IncompleteRead ဖြစ်ခဲ့လို့။ <your-gateway> နေရာမှာ ကိုယ့် domain ထည့်။ ဖိုင်ဖန်တီးရန်: cat > chat.py << 'EOF' ပြီးရင် အောက်ကကုဒ်ကို paste၊ နောက်ဆုံးစာကြောင်း EOF။

import os, json, time, subprocess

URL = "https://<your-gateway>/v1/chat/completions"
KEY = os.environ["GW_KEY"]
MODEL = os.environ.get("GW_MODEL", "deepseek-flash")
PRICE = 1.2  # $ per 1M tokens (right for flash)

def call(body):
    for i in range(3):
        p = subprocess.run(
            ["curl", "-s", "--max-time", "90", URL,
             "-H", "Authorization: Bearer " + KEY,
             "-H", "Content-Type: application/json",
             "-d", body],
            capture_output=True, text=True)
        if p.stdout.strip():
            try:
                return json.loads(p.stdout)
            except Exception:
                pass
        print("(retry...)", flush=True)
        time.sleep(2)
    return None

msgs = []
used = 0
print("Chat start. Type /exit to quit.")

while True:
    try:
        q = input("\nYou: ").strip()
    except EOFError:
        break
    if q == "/exit":
        break
    if not q:
        continue
    msgs.append({"role": "user", "content": q})
    print("(waiting...)", flush=True)
    t0 = time.time()
    d = call(json.dumps({"model": MODEL, "messages": msgs}))
    if not d or "choices" not in d:
        print("Error:", json.dumps(d)[:300] if d else "no response")
        msgs.pop()
        continue
    a = d["choices"][0]["message"]["content"]
    msgs.append({"role": "assistant", "content": a})
    t = d["usage"]["total_tokens"]
    used += t
    print("\nAI:", a)
    print(f"[{time.time()-t0:.1f}s | token {t} | total {used} | cost ~ ${used*PRICE/1e6:.6f}]")
